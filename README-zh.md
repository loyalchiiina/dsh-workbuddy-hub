# dsh-workbuddy-hub

> 在同一个抽屉里管理 WorkBuddy 国内版与国际版账号：凭据、免退出切号、额度与实时模型清单。

> 完整文档以 [English README](./README.md) 为准，本页提供中文导读与关键信息速查。

## 效果图

抽屉顶部是操作按钮（登录国内账号 / 签到 / 网页版 / 刷新 / Star），下面是「国内版 · WorkBuddy」与「国际版 · WorkBuddy AI」两个分组，每组内显示每个账号的昵称、额度、套餐与切号按钮。

## 安装

插件市场搜索 `dsh-workbuddy-hub`，或 `dsh plugin add dsh-workbuddy-hub`。装好重启 DSH 即可看到入口。

## 前置条件

本机已安装并登录 WorkBuddy 客户端（国内版和/或国际版）。插件通过桌面端凭据直接取数，不需要额外配置 API key。

## 🔴 首次安装最常见的问题

插件读不到账号，九成是因为**客户端没装、没登录，或者装在非默认目录**。插件会自动探测安装位置（注册表 + 默认路径 + 全盘扫描），但仍建议先确认客户端能正常打开、已登录。若仍失败，可手动设置环境变量 `WORKBUDDY_ELECTRON_BIN`（国内版）/ `WORKBUDDY_AI_ELECTRON_BIN`（国际版）指向客户端的 exe。

## 能做什么

① 国内版与国际版账号统一管理；② 免退出切换当前账号；③ 实时查询积分额度与套餐；④ 定时自动签到；⑤ 显示 DSH 转接链路状态与模型清单。

## 架构

宿主半边负责读凭据、调上游 API、管理账号台账；客户端半边负责渲染抽屉界面。两侧通过插件注册的回环 HTTP 路由通信。

## 数据流

桌面客户端凭据 → 宿主半边解密读取 → 写入插件自己的账号台账（`~/.dsh/workbuddy-data/`）→ 通过 `/state` 等路由提供给客户端 → 客户端渲染成界面。切号时反向写回客户端凭据位。

## 故障排查

① 模型列表没有 workbuddy 分组：检查 provider 是否为 signed-in；② 取不到额度：确认账号凭据未过期；③ 国际版显示未登录：多数是插件找不到 `WorkBuddyAI.exe`，见上面「前置条件」。
